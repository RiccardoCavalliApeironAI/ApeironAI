# Apeiron AI V10 — Reference First

## Philosophy
Discovery is driven by the reference companies, not by many hard filters.

Initial search inputs:
- Region / country
- Number of results

The engine ranks by business-model similarity:
- own portfolio / brands
- external sourcing / in-licensing
- portfolio expansion
- commercial capability

Therapeutic area is not a default similarity factor.

## Feedback loop
Use 👍 / 👎 on results. Feedback is saved in the browser and supplied to later searches.

## On-demand tools
- Analyze: deeper web research
- Decision makers: Hunter contact lookup
- Find 20 more: incremental discovery, excluding current results

## Environment variables
- OPENAI_API_KEY
- OPENAI_MODEL
- HUNTER_API_KEY
